# InchTitle Variation Titles for WooCommerce

**SEO tagline:** Dynamically inject selected screen-size variations into WooCommerce product H1 titles for TVs and size-based catalogs.

[![WordPress](https://img.shields.io/badge/WordPress-5.8%2B-blue.svg)](https://wordpress.org/)
[![WooCommerce](https://img.shields.io/badge/WooCommerce-5.0%2B-purple.svg)](https://woocommerce.com/)

InchTitle updates the visible product title when shoppers pick a screen-size (or similar) variation—so the H1 matches the configuration they are viewing.

## Features

- Live H1 / title injection from variation attributes (`pa_screen_size` by default)
- Category targeting with hierarchy awareness
- Admin Transformation Studio + sandbox preview
- No database title rewrites
- WooCommerce HPOS / Blocks compatibility declarations
- Clean uninstall

## Installation

1. Place this folder in `wp-content/plugins/inchtitle-variation-titles-for-woocommerce`
2. Activate the plugin
3. Open **WooCommerce →** InchTitle settings and choose categories

## Requirements

- WordPress 5.8+
- PHP 7.4+
- WooCommerce 5.0+
- Variable products with a screen-size (or equivalent) attribute
